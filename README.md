# Mohamed Houij — Premium Portfolio

A full-featured, production-ready React portfolio with dual identity: Creative (Video Editing) and Technical (AI/Engineering).

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run dev server
npm run dev

# 3. Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── components/
│   └── common/          # Navbar, Footer, Cursor, LoadingScreen, etc.
├── pages/
│   ├── Landing.jsx       # Homepage with dual profile selector
│   ├── CreativePortfolio.jsx
│   ├── TechnicalPortfolio.jsx
│   ├── Certifications.jsx
│   ├── Achievements.jsx
│   ├── Gallery.jsx
│   └── Contact.jsx
├── data/
│   ├── technical.js      # Projects, skills, education, certs
│   └── creative.js       # Services, portfolio, testimonials
├── hooks/
│   └── useAnimatedCounter.js
└── index.css             # Global styles, glassmorphism, cursor
```

## 🎨 Design System

- **Fonts**: Syne (display) + Playfair Display (headings) + DM Sans (body) + JetBrains Mono (code)
- **Theme**: Dark luxury (#03030A base)
- **Accents**: Electric Blue (#4FACFE), Gold (#FFB830), Violet (#7B6FF0), Mint (#00E5A0)
- **Effects**: Glassmorphism, custom cursor, animated counters, Framer Motion transitions
